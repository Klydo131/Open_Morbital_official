# Code of Conduct

Open Morbital adopts the Contributor Covenant 2.1 as its code of conduct. The full text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Short version

Be respectful. Disagreement on technical decisions is welcome. Personal attacks, harassment, and discrimination are not.

## Scope

This Code applies to all project spaces — GitHub issues, pull requests, discussions, and any other channel used for project communication.

## Reporting

If someone is violating this Code in a project space, report it via a private GitHub security advisory on this repository (the same channel used for security reports — see SECURITY.md). Reports go to the maintainer only and will be handled discreetly.

## Enforcement

The maintainer will follow the Contributor Covenant enforcement ladder (correction, warning, temporary ban, permanent ban) at their discretion. The goal is to keep the project a place where contribution is comfortable for everyone, not to win arguments.
